# 大诚工具箱品牌重设计初稿

本轮使用内置 image_gen 工具制作品牌方向对比图，暂按项目当前使用的“大诚工具箱”品牌名称设计。

- `existing-icons.png`：现有主应用、Popcat、空/满状态和 PDF 拆分图标预览。
- `brand-concepts-v1.png`：A 折纸、B 套准、C 精密三个概念方向。

概念图中的小尺寸图标用于表达设计方向，并非实际 ICO 渲染验证。选定方向后需要制作矢量母版、透明 PNG 及 16、24、32、48、64、96、128、256 像素的 ICO，并检查真实小尺寸效果。现有应用资源与引用尚未修改。

## 生成提示词

Use case: logo-brand. Asset type: a single landscape brand identity exploration board for a professional Windows prepress utility named 大诚工具箱 (Prepress Toolbox), intended for an actual print shop workflow (PDF split, imposition, file automation). Design an elegant, clear, usable comparison board with THREE evenly spaced vertical columns, each a distinct original brand identity candidate, on a warm white background. Very disciplined editorial layout, clean geometry, excellent typography, no photographic mockups. Exact headline text: 大诚工具箱. Small subheading: PREPRESS TOOLBOX. Column captions exactly: A 折纸 / B 套准 / C 精密. Candidate A: memorable bold folded-sheet monogram loosely suggesting a D, royal cobalt with a small cyan inner fold, flat crisp silhouette, small-size legibility. Candidate B: sophisticated print-registration inspired overlapping geometric shapes, controlled cyan magenta yellow with deep navy anchor, a recognizable single emblem rather than generic registration cross. Candidate C: premium precision-toolbox emblem combining a document and a precise cut/negative-space C/D form, graphite and warm orange, strong simple silhouette. In each column show: one large standalone vector-style brand emblem; the SAME exact emblem as a Windows rounded-square application icon; below this a row of three small cohesive companion icons in that candidate's own style (PDF split document, idle inbox tray, active inbox tray receiving a sheet). All companion icons have no text. Include a compact brand wordmark 大诚工具箱 under each large emblem. Near the bottom show actual small-size tests at approximately 16/32/48px for the respective app icon. Make this a genuine design review sheet, not a promotional poster. Avoid gradients, glow, 3D effects, drop shadows, hairline detail, decorative stars, anime characters, cat photographs, scissors dominating the app logo, extra text, watermarks. Produce a polished 1536x1024 landscape composition with ample space and visually distinct A/B/C choices.
