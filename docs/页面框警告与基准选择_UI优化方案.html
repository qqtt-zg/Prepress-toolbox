推荐精简双行

01警告只说明发生了什么

区分“尺寸不一致”“裁剪框超界”“位置不一致”。页码独立显示，选中状态放到选项里。

02把尺寸作为主要信息

框名弱化，数值对齐；默认保留四位小数。选择用浅蓝底和勾选标记表达。

03详情按需展开

原点、精确坐标及位置示意放入浮层，不推挤下方预设和操作按钮。

04显示选择的实际影响

页面尺寸与排版看板同时更新。“选中基准”表示本次处理选择，尚未修改文件。
