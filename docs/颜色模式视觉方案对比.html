COLOR MODE / VISUAL EXPLORATION

不只读文字，也能识别颜色模式

六种方案均取消前置图标，在现有排版指标的小尺寸里，通过色域、灰阶、边界与背景关系区分“彩色 / 黑白”。点击任意小卡可切换状态。

屏幕预览 · 实际实现仍使用 GDI+

01 · 微光扩散

文字周围出现低饱和色雾；黑白状态则是中性灰雾。柔和，但在很小的控件里识别度一般。
