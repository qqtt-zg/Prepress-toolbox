# 大诚重命名工具 v2.7.0

## 主要更新

- 材料选择框升级为 V5 一体化工作台，优化材料、工艺、订单、排版和预设的紧凑操作布局。
- 预设管理支持分组、排序、批量移动与备份导入导出；打开材料选择框时不再自动应用上次预设，临时大版参数仍跨窗口保留。
- 一式 N 联按 `1122`、一式 N 份按 `123123` 实际修改输出 PDF 页序，可独立于自动排版使用。
- 左侧批量列表增加“批量取消”，成功取消的文件移入监控目录下的“取消文件”文件夹；列头高度固定。
- 改善订单号模式、尺寸长文本显示和标识页、大版尺寸图标反馈。
- 配置保存增加备份和损坏恢复能力。
