## 1. 文档目标

本文件是材料选择框 V4 的施工与验收依据。实现人员必须以终版 HTML 的实际结构、文案、视觉状态和交互行为为准，不得再以早期“屏幕空间瘦身方案”或本文件中的概括性示意替代终版 HTML。

本计划所称“100% 还原”包含四个层面：

1. **结构还原**：控件层级、排列顺序、分组关系与 HTML 一致；
2. **视觉还原**：尺寸、间距、颜色、字体、边框、圆角以及默认/悬停/选中/禁用状态一致；
3. **交互还原**：HTML 中可操作控件的状态转换、联动结果和提示内容全部实现；
4. **业务还原**：原有材料选择、批量分组、排版计算、预设、输出路径和 PDF 预览能力不得因界面重构而丢失。

“100%”不表示浏览器 CSS 与 WinForms 在不同渲染引擎下每个抗锯齿像素完全相同。验收含义为：在 100% DPI 基准环境中，布局几何误差不超过 1px、颜色使用相同 RGB 值、文字和状态完全一致；125% 和 150% DPI 下允许系统缩放产生亚像素差异，但不得出现裁切、重叠、错位或不可操作控件。

## 2. 唯一基准、实施边界与冲突裁决

### 2.1 唯一设计基准

唯一基准文件：

```text
docs/材料选择框终版一体化工作台.html
```

编码开始前必须记录以下信息，并追加到本节下方：

- 文件 SHA-256；
- 文件最后修改时间；
- Chrome/Edge 100% 页面缩放下的基准截图；
- `.v4-workbench-wrapper`、`.v4-left-panel`、`.v4-right-station` 的实际 `getBoundingClientRect()`；
- 预览折叠和展开状态的实际宽高；
- 左侧展开和折叠状态的实际宽高。

HTML 更新后，必须重新生成上述信息；旧截图和旧尺寸立即失效。

### 2.2 还原范围

纳入 WinForms 还原范围：

- `.v4-workbench-wrapper` 内的左侧批量工作台；
- `.v4-workbench-wrapper` 内的右侧材料与排版工位；
- 预设右键菜单；
- 页面框异常阻断弹窗；
- 路径选择浮层；
- PDF 预览折叠区。

不纳入应用窗体的展示辅助内容：

- HTML 页面最外层灰色背景；
- HTML 顶部标题、方案徽章和演示控制栏；
- HTML 右侧像素标尺；
- 仅用于原型演示的 Toast 文案。

原型外壳中的控制行为应由窗体内部对应按钮实现，不能因为排除演示外壳而丢失功能。

### 2.3 HTML 内部冲突的裁决

终版 HTML 中存在演示状态与业务状态不完全一致的情况，按以下规则实现：

| 冲突项 | 裁决结果 |
|---|---|
| 顶部演示复选框默认选中，但预览面板带 `collapsed` | 窗体首次打开默认折叠预览；之后恢复用户上次状态 |
| 二组头部初始显示“直角”，模拟数据中第 4 款为 `round` | 初始截图保持 HTML 文案；选择第 4 款并发生联动后更新为圆角状态 |
| HTML 标尺写 345/590px，但右侧内容未固定 345px | 以浏览器真实 DOM 测量值为视觉基准；345/590 仅保留为优化目标，不能覆盖真实边界 |
| HTML 中“尺寸”弹窗写 PDF 尺寸，设计语义描述为成品净尺寸 | 看板显示和编辑成品净尺寸；提示文案统一为“请输入成品尺寸宽×高（单位 mm）” |

任何新增冲突必须先补入本表，再编码；不得由实现人员自行猜测。

### 3.2 核心状态

以下状态必须具有唯一数据源，不允许只改变控件外观：

| 状态 | 数据源 | 需要同步的界面 |
|---|---|---|
| 当前编辑文件 | 当前批量条目 ID/路径 | 标题、订单、序号、数量、尺寸、排版看板、预览 |
| 左侧面板展开状态 | `_isBatchPanelExpanded` | 窗体宽度、左侧可见性、主按钮文案、单款按钮可见性 |
| 当前材料 | `SelectedMaterial` | 材料按钮、状态文字、当前联动组、AppSettings |
| 覆膜类型 | 现有膜类型字段 | 覆膜按钮、分组胶囊、预设 |
| 模切形状及圆角 | 现有形状字段 + 圆角半径 | 形状按钮、R 输入框、分组胶囊、预设 |
| 排版配置 | 现有排版配置模型 | 6 宫格、分组胶囊、预览、处理结果 |
| 预览状态 | `_isPreviewExpanded` | 折叠按钮、预览高度、窗体高度、位置持久化 |
| 分组锁定状态 | 分组模型 | 锁定徽章、边框/底色、是否接收右侧参数同步 |

### 3.3 尺寸策略

- 右侧工位逻辑宽度固定为 360px；
- 左侧批量工作台逻辑宽度固定为 520px；
- 左侧展开后的逻辑总宽为 880px，不含系统窗体非客户区；
- 预览面板逻辑高度为 245px；
- 其余高度在 Phase 0 使用真实 DOM 测量冻结，不再把未经验证的 345px 当作硬编码值；
- WinForms 应使用 `ClientSize` 对比 HTML 内容区，不得把标题栏和系统边框计入 HTML 高度；
- `AutoScaleMode`、设计 DPI 和字体必须在 Phase 0 一并冻结。

- 组名（例如“【一组】”）；

- **联动与锁定视觉转换**：
  - 联动状态：徽章使用浅绿底 `#F6FFED`、边框 `#B7EB8F`、文字 `#52C41A`；卡片保持浅蓝外框 `#91CAFF`；接收右侧工位参数同步；

### 5.4 分组表格

| 列 | 宽度 | 对齐 | 行为 |
|---|---:|---|---|
| 序号 | 32px | 居中 | 点击选中整行，等宽字体 |
| 文件名 | 155px/剩余空间 | 左 | 状态圆点 + 省略号 + Tooltip |
| 订单 | 50px | 左 | 等宽字体，支持原有就地编辑能力 |
| 数量 | 55px | 居中 | 行内常态输入框视觉，并同步右侧当前款 |
| 页数 | 45px | 居中 | 只读，弱灰文字 |
| 尺寸 | 65px | 居中 | 只读，等宽深蓝文字 |
| 排版/版数 | 85px | 居中 | 随排版计算刷新，等宽蓝色文字 |

表头和数据行高度均为 26px。必须实现以下原生渲染细节以 100% 还原 HTML：

1. **数量列常态输入框视觉绘制（CellPainting 机制）**：
   - WinForms 默认 DataGridView 单元格在非编辑态为纯文本，无法还原 HTML 中常驻的 `<input class="table-qty-input">`；
   - 必须在 DataGridView 的 `CellPainting` 事件中接管数量列的绘制：在单元格中心区域绘制 48×20px、圆角 2px、边框 `#CBD5E1`、背景 `#FFFFFF` 的输入框外观，内部使用 `Consolas` 10.5pt 加粗字体居中绘制数值；
   - 用户单击该单元格时立即触发 `BeginEdit` 进入编辑，限制编辑框大小为 48×20px；
   - 失去焦点或按回车提交修改后，即时触发业务更新，若修改行恰为右侧当前激活款，同步更新右侧工单舱的 `v4InputQty`。
2. **文件名列状态圆点绘制**：
   - 在文件名单元格文本左侧绘制直径 6px 的圆形状态指示灯：当前编辑中为 `#1677FF`（正在编辑），待处理为 `#94A3B8`（排队中），已完成为 `#52C41A`；
3. **行选中高亮**：
   - 当前激活编辑行使用全行底色 `#E6F4FF`，文件名文字加粗并使用深蓝 `#0958D9`，序号高亮加粗。

## 6. 右侧工位规格

### 6.1 标题栏

- 高度：26px；
- 左侧包含待处理列表展开/折叠按钮和当前文件名；
- 文件名超长时显示省略号，Tooltip 显示完整名称；
- 右侧为窗口置顶按钮；
- 置顶按钮必须真实切换 `TopMost`，并有选中状态，不得只是装饰图标。

### 6.2 常用材料区

- 4列×4行；
- 15 个快捷材料按钮 + 1 个更多材料下拉框；
- 材料集合来自 `AppSettings.Material`，HTML 中的材料名称作为基准测试数据；
- 状态行显示“已选: XXX”或“未选择材料”；
- 清除按钮同步清空 `SelectedMaterial`、按钮状态、当前联动组以及持久化配置；
- 默认、悬停、选中样式分别与 HTML 一致；
- 材料名称过长时显示省略号和 Tooltip。

### 6.3 独立输出路径栏

- 高度：27px；
- 左侧标签 `输出:`；
- 中部只读路径显示使用等宽字体和省略号；
- 右侧按钮 `📂 切换目录 ▾`；
- 使用 `ToolStripDropDown + ToolStripControlHost` 承载现有 `folderTreeView`；
- 点击外部、按 Esc、选择有效目录后均关闭；
- 路径无效时不得关闭，并显示错误提示；
- 目录选择后同步 AppSettings、预设和当前输出模型；
- 浮层宽度不得小于路径栏有效宽度，最大高度按 HTML 基准测量值设置。

### 6.4 覆膜与形状矩阵

覆膜选项：

- `✨ 光膜`；
- `🌫️ 哑膜`；
- `🔴 红膜`；
- `🚫 不过膜`。

形状选项：

- `▢ 直角`；
- `○ 圆形`；
- `◇ 异形`；
- `▢ 圆角`。

行为与技术落地要求：

- 每行四项等宽（各占 25%，每项约 80px），首尾 3px 圆角，中间边框连续合并；
- 单选状态同步业务模型、当前联动组和预设；
- **圆角按钮原地内嵌微型输入框技术方案**：
  - WinForms / AntdUI 原生按钮无法直接挂载可聚焦的输入框子控件，故模切形状矩阵第四项采用**复合面板控件（Composite Round Shape Panel）**实现；
  - 面板外框尺寸严格锁定为固定宽度（约 80px）× 25px 高度，与前三个形状按钮平齐并共享分段边框；
  - 面板内部构建两套互斥呈现层：
    1. **非激活/普通态**：居中呈现 Label `▢ 圆角`；
    2. **原地激活态**：水平居中流式布局，包含前缀 Label `▢ R`、中心 24×17px `AntdUI.Input`、后缀 Label `mm`；
  - 点击选择“圆角”时，切换至原地激活态，通过 `BeginInvoke` 触发输入框自动聚焦并全选当前半径值（默认 3）；
  - 输入框限制只接受合法正整数/浮点数，按下 Enter 或失去焦点触发半径持久化与排版联动；
  - 切换回其他形状时，面板恢复显示普通 Label，但保留最后一次合法半径值；
  - 整个切换过程仅改变内部子控件 Visible，面板外框几何尺寸恒定不变，杜绝任何 1px 的拉伸、跳动或换行。

### 6.5 2×2 工单参数舱

使用 2行×2列 `TableLayoutPanel`，行列均为 50%。

| 象限 | 控件 | 必须实现的行为 |
|---|---|---|
| 左上：订单 | 订单输入 + 正则模式菜单 | 完整显示长订单号；模式菜单沿用现有规则 |
| 右上：序号 | 序号输入 + Excel 反查按钮 | 按钮切换启用状态并持久化 |
| 左下：数量 | 多值数量输入 + 增量步长 | 支持逗号多值；同步左侧当前行 |
| 右下：一式 N 联 | Checkbox + 数量 + 联/份 + 模式 | 未勾选时禁用后续控件；勾选后恢复 |

输入校验失败时不得关闭窗体，错误必须定位到具体控件。

### 6.6 排版控制行和 6 宫格看板

控制行必须包含：

- `启用自动排版计算`；
- `平张 / 卷装`；
- `连拼 / 折手`；
- `标识页`。

6 宫格必须依次为：

1. **网格**：宽 48px，大字使用 Primary 蓝 `#1677FF`，点击可打开行列设置；
2. **布局数**：宽 48px，大字使用 MetricCount 橙 `#FA8C16`，根据网格实时计算；
3. **角度**：宽 40px，大字使用 RepeatPurple 紫 `#722ED1`，点击在 0°/90° 间切换；
4. **尺寸**：自适应弹性宽度（1fr），独占浅蓝底 `#F0F7FF`、浅蓝边框 `#91CAFF`、大字使用 PrimaryDark `#0958D9`，点击触发成品净尺寸微调弹窗；
5. **出血**：宽 48px，大字使用 MetricBleed 粉红 `#EB2F96`，点击按 0.0mm / 1.5mm / 2.0mm / 3.0mm 循环切换；
6. **颜色**：宽 50px，大字彩色模式为 MetricColor 青 `#13C2C2`（🎨彩色），黑白模式为 `#595959`（⚪黑白），点击切换。

行为与技术落地要求：

- **纯净尺寸微调弹窗技术落地（替代 HTML 原型 prompt）**：
  - 点击“尺寸”格时调用 `AntdUI.Modal.open` 轻量输入弹窗，标题为“微调成品净尺寸”，提示说明“请输入成品尺寸宽×高（单位 mm）”，输入框自动预填当前尺寸（如 `80×45`）；
  - 智能分隔符解析引擎：支持用户输入 `*`、`x`、`X`、`×` 或空格（例如输入 `80x45`、`80*45`、`80 45` 均自动规范转换为 `80×45`）；
  - 严格数值校验：宽与高必须为大于 0 的合法数值；若格式不符给出轻量消息提示并不改写原参数；
  - 确认后即时刷新 6 宫格尺寸显示、左侧激活行尺寸列、排版计算引擎及底部预览；
- 自动排版关闭后，相关自动计算停止但现有值保留；
- 所有变化同步当前联动组、预览和最终处理参数；
- 每个宫格的列宽、颜色和字体以 HTML DOM 基线为准。

HTML 中的“智能预检防御就绪”和“模拟触发”属于原型说明，不在生产界面常驻显示；真实异常由 PDF 分析流程触发。

### 6.7 预设胶囊栏

- 不显示“预设:”前缀；
- 不显示齿轮和单独的新建预设按钮；
- 胶囊按钮高度 23px，圆角 12px，激活态浅蓝底 `#E6F4FF`、蓝边 `#1677FF`、文字加粗；
- **横向平滑滚动与无缝无滚动条技术方案**：
  - HTML 中预设栏采用 `scrollbar-width: none` 实现了无滚动条的横向滑动，WinForms 原生容器开启 `AutoScroll` 会产生粗灰色 Windows 滚动条破坏界面美观；
  - `presetFlowPanel` 必须隐藏原生物理滚动条（通过重写 `WndProc` 拦截 `WM_NCCALCSIZE`，或调用 Windows API `ShowScrollBar(Handle, SB_BOTH, false)` 消除物理滚动条）；
  - 容器统一捕获鼠标滚轮事件（`OnMouseWheel`），将垂直滚轮滚动量平滑转换为水平滚动偏移（调节 `AutoScrollPosition` 或内部控件 `Left` 偏移），提供与 Web 相同的无缝横向滚轮滑动体验；
- 左键应用预设并切换 Active 状态；
- 右键菜单包含：应用、覆盖保存、另存为、编辑、管理排序、删除；
- 菜单点击外部或按 Esc 关闭；
- 预设应用必须更新所有关联控件，而非只更新尺寸和出血；
- 删除当前 Active 预设后清除 Active 状态并刷新列表。

### 6.8 底部操作栏

- 左侧提示：`💡 预设支持右键管理/另存`；
- 右侧依次为：`仅处理当前款`、`取消`、主确认按钮；

- 左侧列表折叠时隐藏“仅处理当前款”，主按钮为 `确认并继续`；
- 取消按钮沿用现有取消逻辑；

## 7. PDF 预览区规格

### 7.1 折叠控制条

- 高度按 HTML 基准冻结，当前参考值 16px；
- 左侧显示 `页码: 当前页/总页数`；
- 右侧显示展开或折叠提示；
- 整行可点击；
- 箭头方向、提示文字和真实状态必须一致。

### 7.2 预览面板

- 展开高度 245px；
- 使用现有 PdfiumViewer/真实 PDF 预览控件，不用 HTML 的模拟网格替代业务预览；
- 背景、工具栏、边框和缩放信息按 HTML 视觉基准还原；
- 预览随当前文件、排版配置、角度、出血和页码变化刷新；

- 文件分析和页面渲染不得阻塞 UI 主线程；
- 快速切换文件时取消过期预览任务；
- 只允许最后一次选择结果更新界面；
- 预览错误通过 `LogHelper` 记录。

## 8. 页面框异常阻断预检

### 8.1 检测时机

以下操作前必须完成预检：

- 单款确认；
- 仅处理当前款；
- 批量处理全部；
- 自动排版计算首次读取 PDF 页面尺寸。

### 8.2 判定规则

对所有参与处理的 PDF 页执行：

1. 读取 MediaBox 和有效 CropBox；
2. CropBox 缺失时按 PDF 规范视为 MediaBox，不触发差异警告；
3. 将宽、高、Left、Bottom 转换为毫米；
4. 页面旋转只用于展示尺寸，不改变页面框原始差异判断；
5. 任一边尺寸或原点差异绝对值大于 0.1mm 时视为有效差异；
6. 多页文件任一页异常即标记该文件异常；
7. 批量处理中汇总所有异常文件，不重复弹出多个模态框。

容差必须提取为常量并覆盖边界测试。

### 8.3 弹窗内容和行为

弹窗必须显示：

- 文件名和异常页码；
- CropBox 尺寸及原点；
- MediaBox 尺寸及原点；
- 宽高差值；
- 空白页尺寸不匹配和裁切线偏移风险；
- 建议先统一页面框的说明。

按钮：

- `停止操作，先去统一页面框`：返回取消结果，不改变文件；
- `已知晓风险，强行继续`：只放行本次操作，不永久关闭后续预检。

弹窗关闭按钮、Esc 和点击遮罩均按“停止操作”处理，避免误放行。
