输出路径，应该怎样选？

针对材料选择框 360px 工位，下面四种方案都保持路径可见、切换动作短、不会遮挡主要参数。点击左侧方案并直接操作原型。

工作台宽度 360px
路径行高度 30px
推荐点击数 ≤ 2

SELECT A PATTERN

建议最终采用 01 为主入口，并把 02 的“最近 / 常用路径”放在浮层顶部，形成混合方案。

PATTERN 01 / TREE POPOVER

目录树浮层

点击按钮后在路径行下方展开完整目录树。保留用户熟悉的层级结构，改动成本最低，也最贴合当前 HTML 设计稿。

PATTERN 02 / QUICK DESTINATIONS

常用路径快捷面板

把生产中最常用的目录做成两列快捷卡片，选择一次即切换；底部保留“浏览全部目录”作为兜底。适合路径稳定、重复操作多的场景。
