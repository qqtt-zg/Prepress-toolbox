# 材料选择分组联动缺陷修复需求

## 目标

修复材料选择框左侧分组工作台在监控文件动态追加、跨组拖放和预设禁用状态方面的回归，同时保持现有材料/排版业务行为不变。

## 已确认行为

1. 锁定分组后，监控文件夹新增文件进入当前材料选择窗口：
   - 既有锁定分组的 `GroupId`、参数、成员及锁定状态保持不变。
   - 无论文件名是否带保留标记，新文件都进入当前未锁定的联动分组；若不存在可用联动分组，则创建一个未锁定联动分组。
2. 未锁定联动分组之间允许通过拖放移动文件。
3. 锁定分组完全禁止成员变更：既不允许拖入或拖出，也不接收动态追加文件；拒绝拖放时所有数据保持原样。
4. 窗体右侧/全局预设右键菜单在左侧文件列表面板及其动态子控件区域必须保持禁用；左侧专属菜单仍可按原规则工作。

## 非目标

- 不重做界面布局。
- 不修改 PDF 解析、排版计算或监控文件夹的总体生命周期。
- 不引入新依赖。
- 不处理与本任务无关的现有主题按钮改动。

## 验收标准

- 动态追加文件后，锁定组对象的稳定身份、锁定状态和原成员可验证地保持不变。
- 新文件继承目标联动组参数并属于该组。
- 未锁定组 A 的文件可拖至未锁定组 B，并同步更新全局批次项。
- 任一源组或目标组锁定时，拖放返回拒绝且不发生部分更新。
- 鼠标位于左侧面板或任一动态分组子控件上、以及键盘焦点位于该区域时，全局预设菜单均不显示。
- 排序、折叠及重新展开左侧面板均不改变既有分组身份、成员与锁定状态。
- 新增回归测试覆盖以上场景，目标测试、完整测试和 Debug 构建通过。

## 决策边界

- 可自主选择最小的内部辅助方法以实现可测试性。
- 拒绝拖放的 UI 提示可沿用现有无操作反馈模式；不得弹出阻塞式确认框。
- 保留用户工作区中已存在的主题可读性改动，不覆盖或回退。
