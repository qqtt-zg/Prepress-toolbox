# Deep Interview 交付件：材料选择框一体化工作台 V5 终版重构需求规格书

## 1. 背景与目标
基于 `docs/材料选择框终版一体化工作台.html` 的最终定稿效果，将 `MaterialSelectFormModern`（材料选择框）从原有的散落控件架构彻底重构为现代化、一体化、白底细线框卡片化的流水线工位架构。

## 2. 核心范围与实施边界
- **纳入重构范围**：
  - 右侧流水线工位（360px）全部视觉与交互组件重构；
  - 窗体双联体（880px / 360px）与展开预览（753px / 508px）尺寸系统；
  - 常用材料纯净 4×4 网格（无标题/清除文字）；
  - 独立全宽输出路径栏；
  - 工艺开关矩阵（覆膜 + 模切形状 + 圆角原地 R 输入）；
  - 2×2 工单参数舱（订单正则 / 序号反查 / 数量步长 / 一式N联）；
  - 纯净 6 宫格排版看板（尺寸纯白无框只读，由文件自动解析，不可修改）；
  - 快捷方案预设卡片（StyleLine 标签页 + 3px 微圆角白底按钮 + 右键管理）；
  - 底部沉底操作栏（左侧范围切换，右侧取消与确认并继续）；
  - 16px 折叠控制条与 245px PDF 预览面板贴合系统。
- **排除范围（Non-Goals）**：
  - 左侧已有成熟批量列表、文件拖拽排序、分组锁定服务的核心逻辑不变；
  - 排版计算引擎底层逻辑不变。

## 3. 验收标准
1. **构建要求**：.NET Framework 4.8 Debug/Release 构建 0 错误；
2. **尺寸契约**：单工位折叠 360×508px，单工位展开 360×753px，双联体折叠 880×508px，双联体展开 880×753px，误差不超过 1px；
3. **视觉要求**：各模块全量采用纯白底 + 细灰框（`#d4dbe4`），预设按钮 3px 微圆角；
4. **交互要求**：操作栏顺流沉底，左侧幽灵按钮切换范围，右侧确认与取消；
5. **测试覆盖**：尺寸契约测试、主题测试及核心交互测试全部通过。
