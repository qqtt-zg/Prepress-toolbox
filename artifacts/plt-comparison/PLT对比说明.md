# 1.plt 与 2.plt 对比

来源：`C:/Users/admin/Desktop/1.plt` 与 `C:/Users/admin/Desktop/2.plt`。仅读取原文件；未修改或发送到设备。

## 已确认的差异

| 项目 | 1.plt | 2.plt |
|---|---|---|
| 连续闭合刀路 | 52（50个异形、2个小矩形） | 52（50个异形、2个小矩形） |
| PU 指令 | 52 | 52 |
| PD 指令 | 3008 | 1408 |
| 单个异形的 PD 坐标段 | 60，其中2段长度为0 | 28，无零长度段 |
| 异形起点位置 | 40个右下侧，10个右上侧 | 50个均为右下侧 |
| 异形遍历顺序 | 5列，每列10个，上下交替的蛇形顺序 | 10行，每行5个，由右向左；行间Y增加 |
| 两个小矩形的顺序 | 在50个异形之前 | 在50个异形之后 |
| LT 指令 | 3 | 50 |
| SP1 指令 | 3 | 52 |
| SP0 指令 | 1，位于末尾 | 1，位于末尾 |
| PW 笔宽参数 | 0.01 | 0.350 |
| VS 速度参数 | 32 | 32 |

所有刀路内部都没有PU，所有刀路的末坐标都回到各自起点。以PU/PD状态切换计，两份文件均有52次从抬笔状态进入落笔状态；连续PD不会再次发生该状态切换。

1.plt 在异形中包含100个零长度PD，每个异形首尾各一个。例如：

```text
PU790 11594;
PD790 11594;
PD1262 12404;
...
PD790 11594;
PD790 11594;
PU790 10364;
```

2.plt 在各个异形之间重复输出状态设置：

```text
PD2829 -5872;
LT;
SP1;
PU1469 -5872;
PD1941 -5061;
```

1.plt 改从右上侧起刀的刀路编号（包含两个小矩形的总顺序编号）：6、10、15、19、26、30、35、39、46、50。其余异形起点在右下侧；各异形行进方向均一致，没有混合正反方向。

仅统计50个异形之间的中心定位移动，1.plt 的Y坐标累计绝对变化为55362.5原始单位，2.plt 为11070.5原始单位，约为5倍。这不包括轮廓内部移动或两个小矩形；中心定位移动只是排版遍历方式的指标，并非机器实际送料距离。

## 判断与限制

补充几何核对：1.plt 全部刀路的坐标范围为 X=82～6723、Y=80～12594；2.plt 为 X=-3320～3322、Y=-6316～6199。整体跨度分别为6641×12514与6642×12515，基本相同，但原点不同。将对应格位的异形轮廓外接框中心对齐后，双向密集采样的最大轮廓偏差约为2.498个原始坐标单位，说明两者的曲线折线化结果也有细微差异，并非只改变对象排列。该数值未换算设备单位或应用设备缩放。

两个小矩形的绕行方向相反，50个异形的绕行方向均一致。1.plt 的更多PD坐标段表示更密集的折线采样；不表示更多实际抬落刀次数。

- 1.plt 的对象遍历顺序有规律，是按列蛇形；与正常文件的按行顺序不同。
- 1.plt 的落刀起点确实存在两类位置，是本次“起落位置不一致”的直接证据。
- 未发现虚线式中途抬刀、开放轮廓或刀路之间的落刀连接。
- 重复坐标及较少的LT/SP1可能影响特定设备软件的解析，但仅凭两个文件不能确定哪一项造成设备识别失败。
- 两份文件的排版坐标原点及笔宽也不同，不能将全部差异归因于PDF对象结构。
- 是否在PDF导入、排版或PLT导出时发生起点变化与路径排序，仍需排版前后PDF及转换软件设置定位。项目当前代码按模板路径顺序输出，不生成PLT，也不排序50个排版副本。
